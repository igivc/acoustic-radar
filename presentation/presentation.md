# Как обнаружить синхросигнал?

Нормированная взаимная корреляция:

$$
r[k] =
\frac{
\sum_{n=0}^{M-1}x[k+n]s[n]
}{
\sqrt{
\sum_{n=0}^{M-1}x[k+n]^2
\sum_{n=0}^{M-1}s[n]^2
}
}
$$

В коде среднее не вычитается. Выбираем максимум и принимаем маркер при $r \ge 0{,}75$.

# Генерация chirp на C++

```cpp
double phase = 2.0 * std::numbers::pi *
    (f0 * t + 0.5 * (f1 - f0) * t * t / duration);

double sample = amplitude * std::sin(phase);
```
