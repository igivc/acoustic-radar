Замедляем обработку и наблюдаем, где теряются данные.

Учебная модель обмена данными. Она не измеряет скорость C++-программы. Один шаг — callback на 512 кадров. Кольцо вмещает 256 таких блоков, то есть 131072 кадра. В приложении элементы передаются по одному кадру; здесь блок — неделимая единица обмена. Корреляция и FFT показаны как этапы. Модель не вычисляет их: позиции маркеров заданы заранее.

Автопоказ замедлен: один callback раз в 40 мс экрана вместо 10,67 мс сигнала. Сценарии переполнения сразу выполняют несколько секунд модельного времени, чтобы не ждать на сцене.

Кольцо: место записи и чтения

SPSC · ОДИН ПИШЕТ, ОДИН ЧИТАЕТ

Один сектор объединяет 16 блоков. Подсветка показывает занятые физические ячейки; W и R — позиции следующей записи и чтения. При полном кольце позиции совпадают, но write − read = 256.

    Переполнение кольца теряет исходные кадры. Переполнение очереди SDL удаляет уже рассчитанные спектры. Эти события считаются отдельно и по-разному влияют на анализ.

    Исходный индекс растёт на 512 при каждом callbackwrite растёт только при успешной записи блокаЛокальный индекс = абсолютный индекс − basemarker = base + localMarkerПосле анализа: discard = localMarker + 48000 − 512

    Один спектральный кадр содержит 48000 аудиокадров, а не один блок PortAudio. В модели сборщик использует те же условия длины цикла и сохраняет 512 кадров перед ожидаемым следующим маркером.
