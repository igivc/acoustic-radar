OUTPUT 1 посылает короткий маркер в электрическую петлю. OUTPUT 2 одновременно начинает более длинный акустический chirp. После его окончания микрофон INPUT 2 продолжает принимать послезвучие.

Как INPUT 1 находит начало кадра →
s(t) = A · e(t) · sin(φ(t))

Частота задаёт скорость изменения фазы. Огибающая плавно включает и выключает сигнал. Амплитуда задаёт его общий уровень.

t = n / 48000; T = durationMs / 1000f(t) = f₀ + 1000 · t / Tφ(t) = 2π · (f₀ · t + ½ · 1000 · t² / T)0 ≤ t < 0,01: e(t) = ½ · (1 − cos(πt / 0,01))0,01 ≤ t ≤ T − 0,01: e(t) = 1T − 0,01 < t < T: e(t) = ½ · (1 − cos(π(T − t) / 0,01))T ≤ t < 1: s(t) = 0
