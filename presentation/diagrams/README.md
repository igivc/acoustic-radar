# Схема взаимодействия классов

- [class-pipeline.svg](class-pipeline.svg) — готовая схема для слайда, 1920×1080. Откройте в браузере, Inkscape или вставьте в презентацию. Подписи остаются текстом, позиции и цвета можно редактировать в SVG.
- [class-pipeline.mmd](class-pipeline.mmd) — Mermaid-исходник с той же структурой и палитрой. Вставьте его содержимое в Mermaid Live Editor для изменения связей. Mermaid сам размещает элементы, поэтому расположение после экспорта может отличаться от SVG.

Компоновка и пастельные цвета приближены к предоставленному образцу: оборудование слева, аудиопоток сверху по центру, основной поток справа, рабочий поток внизу.

Схема описывает непрерывный режим. Вызовы и маршруты сверены с `src/audio.cpp`, `src/processing.cpp`, `src/main.cpp`, `src/sync.cpp` и `src/spectrum.cpp`. Объединённые стрелки оборудования показывают выход и возвращающийся вход; это разные каналы звуковой карты. Очередь `ready_` принадлежит `ProcessingWorker`: анализатор возвращает результат через `CycleProcessor`, после чего рабочий поток публикует его в очереди. `main()` получает результаты методом `take()` и передаёт их `Spectrogram`.

На схеме возврат результатов показан отдельными стрелками: `SpectrumAnalyzer → CycleProcessor → ProcessingWorker`. Запись в очередь показана только связью `ProcessingWorker → ready_`.
